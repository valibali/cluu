## Plan -> Chapter Mapping (39 plans)

1. 2026-04-27-pipes.md                              -> doc/book/gotchas.md + doc/book/ipc.md
   Pipe = IPC endpoint with two rights-restricted tokens. Token revocation
   cascade = cleanup mechanism. YAGNI deferral on generation counter was
   deliberate.

2. 2026-04-28-user-envelope.md                      -> doc/book/gotchas.md
   Cluufile strict-mount-mismatch: MOUNT rw against ro envelope fails spawn
   with EACCES. validate_cluufile_against_parent does longest-prefix-match.

3. 2026-04-29-editor.md                             -> doc/book/gotchas.md + doc/book/services.md
   VFS open(O_WRONLY|O_CREAT) on MemFs /tmp times out (task #80) — target
   ext2-backed paths for save. Harness cannot inject escape bytes — drive
   editor from parent shell via send_with_payload. Atomic save via tmp+rename.

4. 2026-05-06-virtio-blk-modern.md                  -> doc/book/gotchas.md + doc/book/storage.md
   Notify batching is biggest throughput lever. DmaPool must forbid
   4 KiB page-boundary cross. WC perf invisible under QEMU TCG.

5. 2026-05-07-phase4-A-workspace-cleanup.md         -> doc/book/gotchas.md + doc/book/testing.md
   11 probe crates moved under userspace/probes/, dropped from
   default-members. 3,612-line commands.rs split into commands/ hierarchy.
   19 test-only builtins extracted to probe binaries.

6. 2026-05-07-phase4-B-cli-and-utils.md             -> doc/book/gotchas.md
   Shared cli.rs parser (clustered short flags, long opts, --, auto
   --help/--version). DRY across 11 existing + 15 new utils. GNU exit
   codes 0/1/2.

7. 2026-05-07-phase4-C-ls-and-vfs-stat.md           -> doc/book/gotchas.md + doc/book/vfs.md
   VfsStat wire-protocol bump cascades through every backend + client.
   Plan as discrete phases; don't sneak fields in.

8. 2026-05-07-phase4-D-job-control.md               -> doc/book/gotchas.md
   Full POSIX job control shipped with ZERO kernel commits —

   procmgr / TTY / shell.

9. 2026-05-07-phase4-E-pipe-reverify.md             -> doc/book/gotchas.md + doc/book/ipc.md + doc/book/testing.md
   Diagnostic-first: run 3-stage smoke, capture failure, THEN fix. Real
   gap was env propagation, not pipe mechanism. Lift ENV trailer into
   shared payload builder.

10. 2026-05-07-phase4-F-shell-misc-builtins.md      -> doc/book/testing.md
    History persists to ~/.cluu_history via VFS. Alias table on
    ShellContext. Each muscle-memory builtin in its own file.

11. 2026-05-09-framebuffer-perf-wc.md               -> doc/book/gotchas.md + doc/book/kernel.md
    Program PAT MSR (0x277) at boot for WC index 1. MAP_DEVICE_WC=0x200.
    New flag bit unused on old kernels = graceful fallback. WC perf real
    only under KVM/baremetal.

12. 2026-05-09-symlink-following-resolution.md      -> doc/book/gotchas.md + doc/book/vfs.md
    Fast symlinks store target inline in 60-byte i_block window.
    inline_block_bytes() re-serialises raw view. Four strip_prefix("/bin/")
    sites replaced with VfsClient::realpath(). Procmgr rejects image
    names containing /.

13. 2026-05-10-fb-atlas-and-devfb0.md               -> doc/book/gotchas.md + doc/book/terminal.md
    Glyph atlas: precomputed [u32; W*H] mask template per char + SIMD
    (mask & fg) | (!mask & bg) blend. /dev/fb0 = DeviceBackend::Fb variant.
    TUI compositor scaffold deferred to separate plan — don't bundle
    independent workstreams.

14. 2026-05-10-tui-compositor.md                    -> doc/book/terminal.md
    Compositor owns VT4. Per-window SHM region via FrameAllocate +
    MAP_FRAME_TOKEN. Single-threaded compose pipeline. Legacy console/TTY
    untouched on VT1-3.

15. 2026-05-11-cluuterm.md                          -> doc/book/terminal.md
    ANSI parser + tty internals extracted into libcluu::ansi +
    libcluu::tty_core so console, cluuterm, tty share ONE parser and ONE
    tty core. /bin/login is separate binary. VT4 pinned.

16. 2026-05-12-autologin-rip.md                     -> doc/book/gotchas.md + doc/book/sessions.md
    try_auto_login no-op when SHELL_AUTOSTART_CMD empty. Shared libcluu

    default entry point on every text VT.

17. 2026-05-12-vtmgr-boot-vt-fix.md                 -> doc/book/gotchas.md
    active_vt was init to 0; boot depended on grant-arrival order. Fix:
    init to DEFAULT_COMPOSITOR_VT, drop boot_switch_pending. Don't make
    boot depend on order of independent grant arrivals.

18. 2026-05-13-compositor-clock-pushmode.md         -> doc/book/gotchas.md + doc/book/terminal.md + doc/book/services.md
    Compositor was polling timeserver every iteration. Fix: subscribe
    once, block on recv, wake on TIME_TICK. Polling a service from a
    render loop is an anti-pattern — subscribe push-mode.

19. 2026-05-13-input-routing-vtmgr.md               -> doc/book/gotchas.md
    vtmgr = single source of truth for active-VT AND sole input router.
    kbd shrinks to pure IRQ/decoder/forward. Two IPC hops per keystroke;
    negligible latency. SOLID for future inputd extraction.

20. 2026-05-13-login-as-compositor-client.md        -> doc/book/terminal.md
    /bin/login becomes compositor client (not cluuterm's child). Cluuterm
    spawned only post-login by procmgr. Architectural inversion where
    system service owned auth flow is removed.

21. 2026-05-13-timeserver-pushmode.md               -> doc/book/services.md
    TIME_SUBSCRIBE_PERIODIC / TIME_UNSUBSCRIBE / TIME_TICK. Subscribers
    grant SEND-only token. Zero cumulative drift (anchored deadlines).
    Auto-revoke dead subscribers. Deadline-driven recv_with_timeout loop.

22. 2026-05-13-vt-hardening.md                      -> doc/book/gotchas.md
    Compositor flushed fb at 60Hz and broadcast FRAME_READY regardless of
    damage. 30 messages piled up at cluuterm ep during posix_spawn block.
    Fix: gate broadcast on actual damage per window. Uncontrolled
    fire-and-forget fan-out to single-threaded server = queue-depth bug.

23. 2026-05-14-bug-c-shell-stdin-via-fd0.md         -> doc/book/gotchas.md + doc/book/procmgr.md
    Bug C: shell input via TOKEN_STDIN push breaks under cluuterm. Fix:
    procmgr opens /dev/... at spawn, builds FDAC, injects via
    spawn_service_with_env. tty shrinks to VFS backend answering pulls.
    Unify on POSIX read(0), delete push.
