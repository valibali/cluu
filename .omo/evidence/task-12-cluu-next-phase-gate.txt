Key Fixes During Todo 11
------------------------
- TCP connect/accept loops: added drain_rx_tx() to process RX frames + drain TX frames
  inside the loop. Without this, SYN sits in tx_queue forever for non-loopback destinations.
- TCP/UDP NET_RECV: deferred reply pattern (like ICMP) — push to pending_recv when no data
  ready, reply when data arrives or connection closes (CloseWait/Closed → return 0).
- pending_recv drain loop: extended to handle TCP + UDP, not just ICMP.
- HTTP server in harness: socketserver.TCPServer on port 9876 (8080 occupied by corporate
  proxy), SO_REUSEADDR enabled, cleanup in finally block.
