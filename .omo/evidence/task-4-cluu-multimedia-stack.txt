## Buffer state machine

BufferState: Free -> Drawing -> Queued -> Displayed -> Free
- acquire: Free -> Drawing (NoFreeBuffer if none free; ForeignSurface if wrong token)
- commit:  Drawing -> Queued (DoubleCommit if already Queued/Displayed; UnacquiredBuffer if Free; StaleSequence if seq mismatch; InvalidRect for bad damage)
- flip:    Queued -> Displayed (displayd-side)
- release: Displayed -> Free (UnacquiredBuffer if not Displayed; StaleSequence if seq mismatch)
- destroy: all buffers -> Free, destroyed flag set, further ops -> InvalidCapability

One outstanding queued commit per buffer (per-buffer, not per-surface). Double-buffered
(NUM_BUFFERS = 2); both buffers may be Queued simultaneously.

## Authority model

No numeric surface ID grants authority. Every state-changing method takes a
`surface_cap_token: u64` parameter. Mismatch -> Error::ForeignSurface. Destroyed
surface -> Error::InvalidCapability. No runtime ACL, no sender_tid interrogation
(AGENTS.md §2, §3, §5).

## Damage coordinate spaces (documented in module-level rustdoc)

- Content damage: client-local surface coords (0,0 = surface origin). Validated
  against (surface_w, surface_h) by the state machine. Out-of-bounds -> InvalidRect.
- Scene damage: compositor output coords (0,0 = output origin). Translated by
  Geometry(x, y). displayd clips to output bounds via Rect::clip_to().
- Backend damage: hardware/scanout coords. Backend narrows scene damage to scanout.

Invariant (from cluu-modal-damage-clamps-border-out.md): offset in damage translation
MUST match offset in compose readback. Documented in module rustdoc.

## Design notes

- display.rs is self-contained: uses only core:: paths, no alloc, no serde.
  Compiles standalone with `rustc --edition 2021 --test` and as a module in the
  no_std cluu_wire crate.
- Follows existing cluu_wire conventions: plain structs, #[derive(Debug, Clone,
  Copy, PartialEq, Eq)], no external dependencies.
- Verb labels (300-307) chosen to not collide with session.rs (89-96, 200) or
  pts.rs (130-140).
- DamageList uses fixed [Rect; 8] array — no Vec, no alloc.
- SurfaceState uses [BufferSlot; 2] — double-buffered, fixed array.
- No unwrap()/panic!/as any in new code (rust-best-practices compliance).
