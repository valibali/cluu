RESIZE LOGIC
------------
- Same size: no-op, return old_address.
- Shrink (new < old): space_unmap trailing pages, update MmapRegionTable.
- Grow in-place (new > old, adjacent range free): space_map_range for extra
  pages at old_addr+old_aligned, update MmapRegionTable.
- Grow + MREMAP_MAYMOVE (in-place blocked): find_first_fit for new size,
  space_map_range at new addr, copy_nonoverlapping min(old,new) bytes,
  space_unmap old, update MmapRegionTable.
- Grow without MREMAP_MAYMOVE (in-place blocked): return MAP_FAILED + ENOMEM.

VALIDATION (before any syscall — returns EINVAL, never panics):
- NULL old_address → EINVAL
- Unaligned old_address → EINVAL
- old_size == 0 or new_size == 0 → EINVAL
- Unsupported flag bits → EINVAL
- old_address not a tracked region (addr+len mismatch) → EINVAL
- space_token == 0 → ENOMEM

MREMAP_DONTUNMAP is accepted but treated as a no-op flag (old range is always
unmapped after relocation). MREMAP_FIXED (5th-arg new_address) is not supported.
