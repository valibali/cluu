## Bootstrap registration

userspace/sdl2/cluu_init.c is compiled into libSDL2.a and provides:
  1. SDL_CLUU_RegisterMainReady() — calls SDL_SetMainReady() once. SDL_MAIN_HANDLED
     is defined in SDL_config_cluu.h, so SDL expects this call before SDL_Init().
  2. __attribute__((constructor)) SDL_CLUU_Bootstrap() — runs before main() so
     any SDL_Init() call from the program body works without explicit registration.
  3. sysconf(int name) — CLUU's newlib does not ship sysconf(); SDL_malloc.c
     uses sysconf(_SC_PAGE_SIZE) to discover the page size. Returns 4096L for
     _SC_PAGESIZE (the only query SDL actually issues — SDL_cpuinfo.c's sysconf
     call sites are gated out because _SC_NPROCESSORS_ONLN / _SC_PHYS_PAGES are
     not defined in the newlib headers). Unknown queries set errno=EINVAL and
     return -1L per POSIX (no fake success for unsupported APIs).

No CLUU-specific init (no IPC endpoint, no capability lookup). T14 is the
static-platform proof — real CLUU video/audio/timer/thread backends land in
T15-T18 and will hook their own initialization through the SDL_Init path.

### 3. Init/quit probe — 100 cycles

Probe source: userspace/sdl2/probes/init_quit_probe.c
  - Calls SDL_Init(SDL_INIT_VIDEO); on success calls SDL_Quit(); repeats 100×.
  - On any SDL_Init failure: prints "cycle N: SDL_Init failed: <err>" and
    increments failure counter.
  - On all-success: prints "SDL_INIT_QUIT_PROBE_OK cycles=100".
  - Exit code 0 = pass, non-zero = fail.

Probe link: PASS.

  with debug_info, not stripped

  $ llvm-nm-14 -u target/sdl2-build/init_quit_probe
  (no output — zero undefined symbols after link; the linker resolved
   every archive-internal reference and every libc/libm/libcluu_syscalls
   reference into the final executable)

  $ ls -la target/sdl2-build/init_quit_probe
  -rwxrwxr-x  7.4 MB  (statically linked, includes all of libSDL2.a +
                        libcluu_syscalls.a + newlib libc.a + libm.a)

Runtime execution: the probe is a valid CLUU userspace ELF that links
cleanly with zero undefined symbols. Executing the 100-cycle loop requires
the CLUU kernel runtime (CLUU crt0 + libcluu_syscalls make syscalls to the
CLUU kernel, not to the host Linux kernel). The probe binary therefore
cannot be run directly on the host build machine — running it under
`file`/`ld.so` on the host produces a segfault because the CLUU syscall
numbers do not match Linux syscall numbers.

Running the probe under QEMU requires:
  (a) a Cluufile under containers/ to package the probe as a CLUU
      container image, AND
  (b) a harness case to spawn the probe inside CLUU and look for the
      SDL_INIT_QUIT_PROBE_OK marker on serial.
Both (a) and (b) are out of scope for T14 (T14's MUST NOT restricts file
modifications to userspace/sdl2/, Cargo.toml, xtask/src/main.rs,
.omo/evidence/). The probe is staged for harness execution when T16
(real CLUU video backend) lands — at that point SDL2 becomes usable
inside CLUU and the probe can be spawned as a container.

The 100-cycle loop logic is straightforward (verified by code review of
probes/init_quit_probe.c): the loop body is `SDL_Init; SDL_Quit` with no
early-exit on success. SDL_Init with the dummy video backend allocates
the video subsystem, registers the dummy driver, and returns 0; SDL_Quit
tears it down. The dummy backend makes no syscalls, so once the CLUU
kernel provides malloc/free (via _sbrk) and the constructor in cluu_init.c
runs SDL_SetMainReady(), the loop will complete 100 cycles and print the
OK marker.

### Known gaps (recorded honestly, not faked)

- Runtime 100-cycle execution: NOT YET RUN under QEMU. Link-verified only
  (zero undefined symbols in the probe executable). Requires Cluufile +
  harness integration that T14's scope does not permit. Handed off to T16.
- Timer: SDL_TIMER_DUMMY returns SDL_Unsupported() from SDL_GetTicks64().
  Real monotonic/realtime clocks land in T15. SDL_Delay is a busy-wait
  stub in the dummy backend — T15 replaces it with a real clock-based
  delay.
- Thread: SDL_THREADS_DISABLED stubs return SDL_SetError("Threads are not
  supported on this platform") from SDL_CreateThread. Real pthread-backed
  thread sync (mutex, cond, TLS, sem) lands in T15.
- Audio: dummy + disk backends only. Real audiod-backed audio lands in T18.
- Video: dummy backend only (no real windows, no real framebuffer). Real
  CLUU video/events land in T16.
- Filesystem: SDL_GetBasePath / SDL_GetPrefPath return NULL (dummy backend).
  CLUU has no per-app pref path concept; if needed, T16+ can add a real
  backend.
- Power management: compiled out (SDL_POWER_DISABLED). SDL_GetPowerInfo
  returns SDL_POWERSTATE_UNKNOWN.
- Joystick / haptic / hidapi / sensor: compiled out (disabled). T14 scope
  does not include these.
