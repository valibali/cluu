  `#![no_std]` + `#![no_main]` on the no_std target; `libcluu::runtime as _`
  supplies the panic handler and `_start` entry stub.
- Host-testability: main.rs uses `#![cfg_attr(not(test), no_std)]` and

  panic handler is gated on target_os = "none" anyway). libcluu and its

  on the host for the test build.
- smoltcp version: 0.13.1 (latest available; `cargo search smoltcp` = 0.13.1).
  Task allowed "0.12.0 (or latest available)". 0.13.1 chosen because the
  Context7 API docs (from main = 0.13.x) match the Interface/Device/poll
  signatures used in the smoke test exactly.

FEATURE MAPPING (deviation from task spec — documented in Cargo.toml)
--------------------------------------------------------------------
The task listed features `iface` and `device-medium`. Neither exists in ANY
released smoltcp version (verified against both 0.12.0 and 0.13.1
Cargo.toml [features]). Real equivalents used:
  task "device-medium"  -> "medium-ethernet"  (enables Medium::Ethernet + pulls "socket")
  task "iface"          -> (none)             (smoltcp::iface module is compiled
                                              unconditionally; no feature gate)
  added "alloc"         -> required so SocketSet (heap-backed managed::Vec)
                           links on the alloc-capable no_std target.
Full feature set: proto-ipv4, socket-tcp, socket-udp, socket-icmp,
socket-raw, socket-dhcpv4, socket-dns, medium-ethernet, alloc.
default-features = false (no std, no phy-raw_socket/tuntap, no log).

smoltcp offline/proxy note: `cargo search smoltcp` succeeded (online),
smoltcp 0.13.1 + deps (byteorder, managed, heapless, hash32, stable_deref_trait,
defmt) resolved and downloaded through the configured proxy.
