  let used = pmm_get_stats(self_token, PMM_STATS_USED_FRAMES).unwrap_or(0);
  let total = pmm_get_stats(self_token, PMM_STATS_TOTAL_FRAMES).unwrap_or(0);

Output format (unchanged):

RISKS / KNOWN LIMITATIONS
═══════════════════════════════════════════════════════════════════════════
1. (misleading_success_output — PARTIAL) The Heap* fields on
   /proc/<pid>/status reflect the VFS SERVER's own allocator, not the target
   PID's. `allocator::stats()` is a per-process local call; there is no
   cross-process allocator-stats IPC. The only per-process cross-process
   memory metric is `space_get_stats` (code/heap/stack PAGE counts), which
   is a different metric (pages, not allocator total/used/peak/free bytes).
   The fields ARE populated from real stats() (not hardcoded — the
   misleading_success_output concern is addressed at the "real vs hardcoded"
   level), but they are VFS's real stats, not PID's. This is documented in an
   inline comment at the status branch. Fixing it properly requires extending
   the ProcInfo wire type (procmgr-common/src/wire.rs) so session-procmgr
   queries each child's allocator and reports it back — explicitly OUT OF
   SCOPE per the task ("do NOT add new syscalls", scope = procfs.rs only).
   Follow-up: a future todo should add `heap: AllocStats` to ProcInfo and
   have session-procmgr collect it from children.

2. (concurrent edit) While this task ran, the wave-1 todo-3 agent (M2 heap
   fragmentation) added a `largest_free: usize` field to AllocStats. My test
   literals include `largest_free` so they compile against the current
   AllocStats. format_status does NOT surface largest_free (out of scope:
   task asked for HeapTotal/Used/Peak/Free only). If todo-3 is reverted but
   todo-2 lands, the test literals would need `largest_free` removed.

3. (test runtime) The `#[cfg(test)]` tests compile but do not run via
   `cargo test` because the vfs crate is no_std+no_main with no host-test
   harness — same as the pre-existing view.rs tests. They document the
   contract and compile-check the seam.
