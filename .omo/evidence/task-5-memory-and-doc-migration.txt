## What changed

Added a 1 MiB bump-pointer nursery in front of LockedAllocator in
userspace/libcluu/src/allocator.rs. The nursery is a tcache-style fast
path for small allocations (<=256 bytes, alignment <=64). The existing
LockedAllocator is preserved (not replaced) and serves as the fallback
for large allocations and all deallocs.

### New types

- Nursery: bump-pointer arena struct with start/end/bump/peak fields.
  Methods: init, is_ready, contains, try_alloc, sweep, used, peak_used.
  Backed by a 1 MiB static BSS array (NURSERY_HEAP, 64-byte aligned).

- NurseryAllocator: wrapper struct containing Mutex<Nursery>,
  AtomicUsize (nursery_start, nursery_end for lock-free dealloc routing),
  and LockedAllocator (inner). Implements GlobalAlloc.
  Methods: new, init, stats, set_oom_handler, nursery_sweep.

### Constants

- NURSERY_SIZE = 1 MiB (within plan's 1-2 MiB range)
- NURSERY_THRESHOLD = 256 bytes
- NURSERY_MAX_ALIGN = 64 bytes

### Allocation routing (GlobalAlloc::alloc)

1. If size <= 256 AND align <= 64: try nursery (bump pointer, O(1))
2. If nursery full: sweep (reset bump to start), retry
3. If still fails or large/over-aligned: fall through to LockedAllocator

### Deallocation routing (GlobalAlloc::dealloc)

1. Load nursery_start/nursery_end from atomics (no lock needed)
2. If ptr in [nursery_start, nursery_end): no-op (nursery is allocation-only)
3. Otherwise: delegate to LockedAllocator::dealloc

### Safety contract

Sweeping reclaims all nursery memory regardless of liveness. Safe only
when callers do not retain nursery pointers across a sweep. In practice:
(a) nursery threshold is 256 B so long-lived objects go to linked-list,
(b) nursery is 1 MiB so sweeps are rare. Pattern: jemalloc tcache,
tcmalloc thread-local FreeList.

### Global allocator change

GLOBAL_ALLOCATOR type changed from LockedAllocator to NurseryAllocator.
LockedAllocator type and impl are preserved (not replaced, not modified).
Public API (init, stats, set_oom_handler) unchanged — same signatures,
now delegating through NurseryAllocator.

### 4. QEMU boot — NOT RUN (QEMU unavailable in this environment)

Expected behavior: Boot CLUU + run
  micropython -c "for i in range(1000): x = [1]*100"
Should succeed. Small list allocations ([1]*100 = 100-element list of
integers) are well under the 256-byte nursery threshold and will be
served by the nursery fast path. If the nursery fills, sweep resets
the bump pointer and the alloc retries — no panic.

If nursery sweep reclaims a live small object, the next alloc to that
address would return stale memory. This is the accepted trade-off of
the tcache/bump-allocator pattern (see safety contract above). The
1 MiB nursery size makes sweeps rare for typical workloads.
