# cluuterm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land a terminal emulator binary (`cluuterm`) that runs in a compositor window, hosts the cluu shell behind `/dev/pts/<id>`, and ships with VT4 boot integration plus a new `/bin/login` binary.

**Architecture:** Extract ANSI parser and tty internals into two new shared libraries (`libcluu::ansi`, `libcluu::tty_core`); add `/bin/login`; add `cluuterm` binary; add VFS pts namespace; pin compositor to VT4 with cluuterm autostarted; refactor legacy tty + console onto the shared libs so there is only one ANSI parser and one tty core in the tree.

**Tech Stack:** Rust (`no_std` userspace, alloc), procmgr-backed IPC, custom newlib syscalls, harness markers under `scripts/harness_run.sh`. Spec: `docs/superpowers/specs/2026-05-11-cluuterm-design.md`.

---

## Conventions used in this plan

- **Build & smoke:** `HARNESS_FORCE_BUILD=1 MARKER_MODE=<marker> bash scripts/harness_run.sh` after any change that touches userspace binaries. Marker must be already added in `scripts/harness_run.sh`. Per memory `feedback_harness_usage_for_subagents.md`, one minimal marker per task; retry vt/manifest flake exactly once.
- **Component tests:** placed under each crate's `tests/` directory or inline `#[cfg(test)]` mod. Run with `cargo test -p <crate>` from the workspace root.
- **Commits:** small, one per task, ASCII-only message, no `--no-verify`, no force pushes. Conventional-commit prefix optional but consistent with recent history (`compositor: ...`, `vfs: ...`, etc.).
- **Spec dest:** every cross-file move keeps line counts roughly visible — if a task moves 500 LOC, the diff should still be reviewable.

- [ ] **Step 2: Port the parser into `Parser::feed`**

In `userspace/libcluu/src/ansi/state.rs`, replace the stubbed `feed` with the real state machine. The body mirrors `VtScreen::write_byte` from console, but emits `Event`s instead of mutating cells. Pseudo-rust shape (fill in the bodies from console):

```rust
impl Parser {
    pub fn feed<F: FnMut(Event)>(&mut self, bytes: &[u8], mut emit: F) {
        for &b in bytes {
            match self.state {
                EscState::Normal => self.feed_normal(b, &mut emit),
                EscState::Escape => self.feed_escape(b, &mut emit),
                EscState::Csi => self.feed_csi(b, &mut emit),
            }
        }
    }

    fn feed_normal<F: FnMut(Event)>(&mut self, b: u8, emit: &mut F) {
        match b {
            0x1B => self.state = EscState::Escape,
            b'\n' => emit(Event::Newline),
            b'\r' => emit(Event::CarriageReturn),
            0x08 => emit(Event::Backspace),
            b'\t' => emit(Event::Tab),
            0x07 => emit(Event::Bell),
            _ => emit(Event::Print(b)),
        }
    }

    fn feed_escape<F: FnMut(Event)>(&mut self, b: u8, _emit: &mut F) {
        match b {
            b'[' => {
                self.state = EscState::Csi;
                self.param_count = 0;
                self.current = 0;
            }
            _ => self.state = EscState::Normal,
        }
    }

    fn feed_csi<F: FnMut(Event)>(&mut self, b: u8, emit: &mut F) {
        match b {
            b'0'..=b'9' => {
                self.current = self.current.saturating_mul(10) + (b - b'0') as u16;
            }
            b';' => {
                self.push_param();
            }
            b'A' => { self.push_param(); emit(Event::MoveCursorUp(self.param(0, 1))); self.reset(); }
            b'B' => { self.push_param(); emit(Event::MoveCursorDown(self.param(0, 1))); self.reset(); }
            b'C' => { self.push_param(); emit(Event::MoveCursorRight(self.param(0, 1))); self.reset(); }
            b'D' => { self.push_param(); emit(Event::MoveCursorLeft(self.param(0, 1))); self.reset(); }
            b'H' | b'f' => {
                self.push_param();
                let row = self.param(0, 1);
                let col = self.param(1, 1);
                emit(Event::MoveCursorAbs { row, col });
                self.reset();
            }
            b'K' => { self.push_param(); emit(Event::EraseLine); self.reset(); }
            b'J' => { self.push_param(); emit(Event::EraseDisplay); self.reset(); }
            b'm' => {
                self.push_param();
                self.apply_sgr(emit);
                self.reset();
            }
            _ => self.reset(),
        }
    }

    fn push_param(&mut self) {
        if self.param_count < self.params.len() {
            self.params[self.param_count] = self.current;
            self.param_count += 1;
        }
        self.current = 0;
    }

    fn param(&self, idx: usize, default: u16) -> u16 {
        if idx < self.param_count && self.params[idx] != 0 {
            self.params[idx]
        } else {
            default
        }
    }

    fn reset(&mut self) {
        self.state = EscState::Normal;
        self.param_count = 0;
        self.current = 0;
    }

    fn apply_sgr<F: FnMut(Event)>(&mut self, emit: &mut F) {
        // Port from console::VtScreen::apply_sgr. The mapping from numeric
        // params (30..37 fg, 40..47 bg, 90..97 bright fg, etc.) to RGB values
        // lives in console as ANSI_COLORS / ANSI_BRIGHT_COLORS. Move those
        // tables here and emit Event::SetAttr / Event::ResetAttr accordingly.
        for i in 0..self.param_count {
            let p = self.params[i];
            match p {
                0 => emit(Event::ResetAttr),
                30..=37 => { self.attr.fg = ansi_color(p - 30); emit(Event::SetAttr(self.attr)); }
                40..=47 => { self.attr.bg = ansi_color(p - 40); emit(Event::SetAttr(self.attr)); }
                90..=97 => { self.attr.fg = ansi_bright_color(p - 90); emit(Event::SetAttr(self.attr)); }
                100..=107 => { self.attr.bg = ansi_bright_color(p - 100); emit(Event::SetAttr(self.attr)); }
                1 => { self.attr.bold = true; emit(Event::SetAttr(self.attr)); }
                _ => {}
            }
        }
    }
}

const ANSI_COLORS: [u32; 8] = [
    0x00000000, 0x00AA0000, 0x0000AA00, 0x00AA5500,
    0x000000AA, 0x00AA00AA, 0x0000AAAA, 0x00AAAAAA,
];
const ANSI_BRIGHT_COLORS: [u32; 8] = [
    0x00555555, 0x00FF5555, 0x0055FF55, 0x00FFFF55,
    0x005555FF, 0x00FF55FF, 0x0055FFFF, 0x00FFFFFF,
];
fn ansi_color(i: u16) -> u32 { ANSI_COLORS[i as usize % 8] }
fn ansi_bright_color(i: u16) -> u32 { ANSI_BRIGHT_COLORS[i as usize % 8] }
```

/// Translate an extended-key code (as emitted by `userspace/kbd`) into the
/// xterm-style CSI byte sequence that should be fed through the line

pub fn encode_extended(extended: u8) -> Option<&'static [u8]> {
    Some(match extended {

        4 => b"\x1b[C",
        5 => b"\x1b[H",

extern crate alloc;
use alloc::vec::Vec;

pub struct HistoryRow {
    pub chars: Vec<u8>,
    pub fg: Vec<u32>,
    pub bg: Vec<u32>,
}

pub struct Scrollback {
    history: Vec<HistoryRow>,
    start: usize,
    len: usize,
    capacity: usize,
}

impl Scrollback {
    pub fn new(capacity: usize) -> Self {
        Self { history: Vec::new(), start: 0, len: 0, capacity }
    }

    pub fn push(&mut self, row: HistoryRow) {
        if self.history.len() < self.capacity {
            self.history.push(row);
            self.len += 1;
        } else {
            self.history[self.start] = row;
            self.start = (self.start + 1) % self.capacity;
        }
    }

    pub fn len(&self) -> usize { self.len }

    pub fn row(&self, idx_from_oldest: usize) -> Option<&HistoryRow> {
        if idx_from_oldest >= self.len { return None; }
        let real = (self.start + idx_from_oldest) % self.capacity.max(1);
        self.history.get(real)
    }
}
```

        write_stdout(b"\r\npassword: ");

fn read_line(mask: bool) -> String {
    let mut buf = String::new();
    let mut byte = [0u8; 1];
    loop {
        if read_stdin(&mut byte) == 0 { continue; }
        let b = byte[0];
        match b {
            b'\r' | b'\n' => return buf,
            0x7f | 0x08 => {

            0x20..=0x7e => {

                if mask { write_stdout(b"*"); } else { write_stdout(&[b]); }
            }
            _ => {}
        }
    }

//! pts (pseudo-terminal slave) namespace backed by per-cluuterm IPC.

extern crate alloc;
use alloc::collections::BTreeMap;
use alloc::string::String;
use alloc::vec::Vec;

const MAX_PTS_SLOTS: usize = 32;

pub struct PtsEntry {
    pub id: u32,
    pub owner_tid: u64,
    pub refcount: u32,
}

pub struct PtsRegistry {
    entries: BTreeMap<u32, PtsEntry>,
    next_id: u32,
}

impl PtsRegistry {
    pub fn new() -> Self { Self { entries: BTreeMap::new(), next_id: 0 } }

    pub fn register(&mut self, owner_tid: u64) -> Option<u32> {
        if self.entries.len() >= MAX_PTS_SLOTS { return None; }
        let id = self.next_id;
        self.next_id = self.next_id.wrapping_add(1);
        self.entries.insert(id, PtsEntry { id, owner_tid, refcount: 0 });
        Some(id)
    }

    pub fn unregister(&mut self, id: u32) { self.entries.remove(&id); }

    pub fn inc_ref(&mut self, id: u32) -> Option<u32> {
        self.entries.get_mut(&id).map(|e| { e.refcount += 1; e.refcount })
    }

    /// Returns `(new_refcount, owner_tid)` so the caller can emit
    /// `PTS_CLOSED_LABEL` when the count hits zero.
    pub fn dec_ref(&mut self, id: u32) -> Option<(u32, u64)> {
        self.entries.get_mut(&id).map(|e| {
            if e.refcount > 0 { e.refcount -= 1; }
            (e.refcount, e.owner_tid)
        })
    }

    pub fn owner(&self, id: u32) -> Option<u64> {
        self.entries.get(&id).map(|e| e.owner_tid)
    }

    pub fn list_paths(&self) -> Vec<String> {
        self.entries.keys().map(|id| {
            let mut s = String::from("/dev/pts/");
            push_decimal(&mut s, *id);
            s
        }).collect()
    }
}

fn push_decimal(s: &mut String, mut n: u32) {
    if n == 0 { s.push('0'); return; }
    let mut buf = [0u8; 10]; let mut i = 0;
    while n > 0 { buf[i] = b'0' + (n % 10) as u8; n /= 10; i += 1; }
    while i > 0 { i -= 1; s.push(buf[i] as char); }
}
```

pub fn handle_pts_write(&mut self, bytes: &[u8]) {
    let cols = self.cols;
    let rows = self.rows;
    self.parser.feed(bytes, |ev| match ev {
        Event::Print(b) => {
            let pos = self.cursor_y * cols + self.cursor_x;
            self.cells[pos] = b;
            self.fg_cells[pos] = self.current_attr.fg;
            self.bg_cells[pos] = self.current_attr.bg;
            self.cursor_x += 1;
            if self.cursor_x >= cols { self.cursor_x = 0; self.cursor_y += 1; }
            if self.cursor_y >= rows { self.scroll_up(); }
        }
        Event::Newline => { self.cursor_y += 1; if self.cursor_y >= rows { self.scroll_up(); } }
        Event::CarriageReturn => self.cursor_x = 0,
        Event::Backspace => if self.cursor_x > 0 { self.cursor_x -= 1; },
        Event::MoveCursorUp(n)    => self.cursor_y = self.cursor_y.saturating_sub(n as usize),
        Event::MoveCursorDown(n)  => self.cursor_y = (self.cursor_y + n as usize).min(rows - 1),
        Event::MoveCursorLeft(n)  => self.cursor_x = self.cursor_x.saturating_sub(n as usize),
        Event::MoveCursorRight(n) => self.cursor_x = (self.cursor_x + n as usize).min(cols - 1),
        Event::MoveCursorAbs { row, col } => {
            self.cursor_y = (row.saturating_sub(1) as usize).min(rows - 1);
            self.cursor_x = (col.saturating_sub(1) as usize).min(cols - 1);
        }
        Event::EraseLine => {
            let row = self.cursor_y;
            for c in 0..cols { self.cells[row * cols + c] = b' '; }
        }
        Event::EraseDisplay => {
            for v in self.cells.iter_mut() { *v = b' '; }
            self.cursor_x = 0; self.cursor_y = 0;
        }
        Event::SetAttr(a) => self.current_attr = a,
        Event::ResetAttr => self.current_attr = Attr::default_attr(),
        Event::Tab => self.cursor_x = ((self.cursor_x / 8) + 1) * 8,
        Event::Bell => {}
        Event::Scroll(_n) => self.scroll_up(),
    });
    // Trigger a render + FRAME_READY (Task 17 supplies render()).
    self.render_and_publish();
}

fn scroll_up(&mut self) {
    let cols = self.cols;
    // push top row into scrollback as a HistoryRow
    let row = HistoryRow {
        chars: self.cells[0..cols].to_vec(),
        fg: self.fg_cells[0..cols].to_vec(),
        bg: self.bg_cells[0..cols].to_vec(),
    };
    self.scrollback.push(row);
    // shift rows up by one
    let total = cols * self.rows;
    self.cells.copy_within(cols..total, 0);
    self.fg_cells.copy_within(cols..total, 0);
    self.bg_cells.copy_within(cols..total, 0);
    for i in (total - cols)..total { self.cells[i] = b' '; self.fg_cells[i] = self.current_attr.fg; self.bg_cells[i] = self.current_attr.bg; }
    if self.cursor_y > 0 { self.cursor_y -= 1; }
}

        let msg = libcluu::ipc::recv_blocking();
        match msg.label() {
            libcluu::ipc::PTS_WRITE_LABEL => {

                let data = self.handle_pts_read(max);
                libcluu::ipc::reply_with_bytes(msg.reply_token(), &data);
            }
            libcluu::ipc::PTS_CLOSED_LABEL => {

                let _ = libcluu::ipc::pts_unregister(self.pts_id);

                crate::input::handle(self, msg);
            }
            libcluu::ipc::COMP_CLOSE_REQUEST_LABEL => {
                let _ = libcluu::ipc::pts_unregister(self.pts_id);
                let _ = libcluu::ipc::comp_win_destroy(self.window_id);
                return;
            }
            _ => {}
        }
    }

pub fn handle(term: &mut Cluuterm, msg: Message) {

fn push_through_discipline(term: &mut Cluuterm, b: u8) {
    let effect = term.discipline.handle_byte(b);

}

fn apply_effect(term: &mut Cluuterm, effect: libcluu::tty_core::line_discipline::Effect) {
    use libcluu::tty_core::line_discipline::Effect;

        Effect::EchoByte(b) => term.handle_pts_write(&[b]),
        Effect::LineReady(bytes) => term.stdin_buf.extend(bytes.iter().copied()),
        Effect::RawByte(b) => term.stdin_buf.push_back(b),
        Effect::Nothing => {}
        // Other variants per current LineDiscipline; mirror legacy tty's apply_effect.
    }
}

use libcluu::atlas::FONT_8X16; // existing font atlas in libcluu
use libcluu::window_shm::WindowShm;
use crate::tty_backend::Cluuterm;

pub const GLYPH_W: usize = 8;
pub const GLYPH_H: usize = 16;

pub fn render(term: &Cluuterm) {
    let cols = term.cols;
    let rows = term.rows;
    let fb_w = (cols * GLYPH_W) as usize;
    for row in 0..rows {
        for col in 0..cols {
            let pos = row * cols + col;
            let ch = term.cells[pos];
            let fg = term.fg_cells[pos];
            let bg = term.bg_cells[pos];
            blit_glyph(&term.shm, fb_w, row, col, ch, fg, bg);
        }
    }
}

fn blit_glyph(shm: &WindowShm, fb_w: usize, row: usize, col: usize, ch: u8, fg: u32, bg: u32) {
    let glyph = &FONT_8X16[ch as usize];
    let x0 = col * GLYPH_W;
    let y0 = row * GLYPH_H;
    for gy in 0..GLYPH_H {
        let bits = glyph[gy];
        for gx in 0..GLYPH_W {
            let on = (bits >> (7 - gx)) & 1 != 0;
            let px = if on { fg } else { bg };
            shm.put_pixel(x0 + gx, y0 + gy, fb_w, px);
        }
    }
}

pub fn pts_path(id: u32) -> [u8; 24] {
    let mut buf = [0u8; 24];
    let prefix = b"/dev/pts/";
    buf[..prefix.len()].copy_from_slice(prefix);
    let mut n = id; let mut digits = [0u8; 10]; let mut i = 0;
    if n == 0 { digits[0] = b'0'; i = 1; }
    while n > 0 { digits[i] = b'0' + (n % 10) as u8; n /= 10; i += 1; }
    let mut pos = prefix.len();
    while i > 0 { i -= 1; buf[pos] = digits[i]; pos += 1; }
    buf
}
