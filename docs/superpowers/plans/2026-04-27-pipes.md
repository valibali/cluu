# CLUU Shell Pipes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land full Unix-style pipelines in the cluu shell — `cat /etc/motd | grep CLUU | head -3` works end-to-end with stderr redirection and SIGPIPE.

**Architecture:** A pipe is one IPC endpoint with two restricted-rights tokens (write-only / read-only) minted from it via `kernel::TokenDerive`. Procmgr owns pipe lifecycle (PIPE_CREATE / PIPE_CLOSE). Newlib gets real `pipe(2)` via fd_table extension. Shell composes pipelines from existing primitives.

**Tech Stack:** Rust no_std for kernel/userspace, libcluu syscall wrappers, cluu_lang pest grammar (already supports pipe operator), QEMU-based test harness via `scripts/harness_run.sh`.

**Spec:** `docs/superpowers/specs/2026-04-27-pipes-design.md`

```rust
/// Allocate a free slot in the pipes vec. Returns (index, generation).
fn allocate_pipe_slot(&mut self) -> (usize, u32) {
    for (idx, slot) in self.pipes.iter_mut().enumerate() {
        if slot.is_none() {
            // Generation lives in the slot itself even when None — store it
            // in a sidecar Vec<u32> instead. Simpler: use index with no
            // reuse for v1 (just push), accept the unbounded growth for
            // small demo runs.
            return (idx, 0);
        }
    }
    self.pipes.push(None);
    (self.pipes.len() - 1, 0)
}

fn pipe_id_encode(index: usize, generation: u32) -> usize {
    ((generation as usize) << 16) | (index & 0xFFFF)
}

fn pipe_id_decode(pipe_id: usize) -> (usize, u32) {
    (pipe_id & 0xFFFF, (pipe_id >> 16) as u32)
}
```

```rust
fn handle_pipe_create(&mut self, _msg: &Message, sender_tid: usize) -> Result<()> {
    // Look up sender's PID for ownership tracking.
    let creator_pid = self.tid_to_pid(sender_tid).unwrap_or(0);

    // Mint the underlying endpoint (root cap is procmgr's IPC token).
    let endpoint = match crate::syscall::endpoint_create(self.token) {
        Ok(ep) => ep,
        Err(e) => {
            return self.reply_pipe_create_error(sender_tid, e);
        }
    };

    // Derive write-only and read-only tokens.
    // Rights bitmask: WRITE = 1<<1 (kernel/src/token/rights.rs).
    // For the writer, we need WRITE rights so it can `send`. For the reader,
    // we need READ rights so it can `recv`.
    const RIGHTS_WRITE: usize = 1 << 1;
    const RIGHTS_READ:  usize = 1 << 0;

    let write_token = match crate::syscall::token_derive(endpoint, RIGHTS_WRITE, 0) {
        Ok(t) => t,
        Err(e) => {
            let _ = crate::syscall::token_revoke(endpoint);
            return self.reply_pipe_create_error(sender_tid, e);
        }
    };

    let read_token = match crate::syscall::token_derive(endpoint, RIGHTS_READ, 0) {
        Ok(t) => t,
        Err(e) => {
            let _ = crate::syscall::token_revoke(write_token);
            let _ = crate::syscall::token_revoke(endpoint);
            return self.reply_pipe_create_error(sender_tid, e);
        }
    };

    let (idx, gen) = self.allocate_pipe_slot();
    let pipe_id = Self::pipe_id_encode(idx, gen);
    self.pipes[idx] = Some(PipeEntry {
        endpoint,
        generation: gen,
        creator_pid,
        write_token,
        read_token,
    });

    // Reply with (status=0, write_token, read_token, pipe_id).
    let reply = Message::new(0, [0, write_token, read_token, pipe_id, 0, 0], 4);
    crate::syscall::ipc_reply(sender_tid, &reply, IpcFlags::empty())
}

fn reply_pipe_create_error(&self, sender_tid: usize, err: Error) -> Result<()> {
    let status = err.as_status();  // existing helper that maps Error -> usize
    let reply = Message::new(0, [status, 0, 0, 0, 0, 0], 1);
    crate::syscall::ipc_reply(sender_tid, &reply, IpcFlags::empty())
}
```

### Task 4: Procmgr `PIPE_CLOSE` handler

**Files:**
- Modify: `userspace/procmgr/src/main.rs`

- [ ] **Step 1: Implement `handle_pipe_close`**

```rust
fn handle_pipe_close(&mut self, msg: &Message, sender_tid: usize) -> Result<()> {
    let pipe_id = msg.words[0];
    let (idx, _gen) = Self::pipe_id_decode(pipe_id);

    let status = if let Some(slot) = self.pipes.get_mut(idx) {
        if let Some(entry) = slot.as_mut() {
            // Per-side close: revoke whichever tokens this caller owns.
            // For v1, we revoke both — the caller is the only legitimate
            // user since pipe(2) is process-local (the receiving children
            // got *separate* token handles passed during spawn, not the
            // creator's tokens).
            let creator_pid = self.tid_to_pid(sender_tid).unwrap_or(0);
            if creator_pid == entry.creator_pid {
                if entry.write_token != 0 {
                    let _ = crate::syscall::token_revoke(entry.write_token);
                    entry.write_token = 0;
                }
                if entry.read_token != 0 {
                    let _ = crate::syscall::token_revoke(entry.read_token);
                    entry.read_token = 0;
                }
                let _ = crate::syscall::token_revoke(entry.endpoint);
                *slot = None;
            }
            0  // success
        } else {
            0  // already closed — idempotent
        }
    } else {
        0  // out of range — treat as already closed (idempotent)
    };

    let reply = Message::new(0, [status, 0, 0, 0, 0, 0], 1);
    crate::syscall::ipc_reply(sender_tid, &reply, IpcFlags::empty())
}
```

NOTE for v1: the "caller is creator" semantic is sufficient because `pipe(2)` is currently used via the shell, and the children receive *minted, derived* tokens during spawn, NOT the creator's original tokens. Token revocation cascades because `TokenDerive`'s child tokens are invalidated when the parent is revoked (per `kernel::TokenRevoke` semantics).

```rust
//! POSIX pipe(2) — wraps PROCMGR_PIPE_CREATE.

use crate::error::Error;
use crate::ipc;
use crate::types::Message;
use crate::posix::{c_int, set_errno, EAGAIN, ENOMEM};
use core::ptr;

const PROCMGR_PIPE_CREATE_LABEL: u32 = ipc::PROCMGR_PIPE_CREATE_LABEL;
const PROCMGR_PIPE_CLOSE_LABEL:  u32 = ipc::PROCMGR_PIPE_CLOSE_LABEL;

#[no_mangle]
pub extern "C" fn pipe(fds: *mut c_int) -> c_int {
    pipe2(fds, 0)
}

#[no_mangle]
pub extern "C" fn pipe2(fds: *mut c_int, _flags: c_int) -> c_int {
    if fds.is_null() {
        set_errno(EAGAIN);  // POSIX-ish: no fd-pair returned
        return -1;
    }

    // Resolve procmgr endpoint (every process has it cached at boot).
    let procmgr_ep = match crate::registry::subscribe_output("procmgr", "spawn") {
        Ok(ep) => ep,
        Err(_) => {
            set_errno(ENOMEM);
            return -1;
        }
    };

    // PIPE_CREATE: empty payload, label only.
    let mut req = Message::new(PROCMGR_PIPE_CREATE_LABEL, [0; 6], 0);
    let mut reply = Message::new(0, [0; 6], 0);
    if let Err(_) = crate::ipc::call(procmgr_ep, &mut req, crate::IpcFlags::empty()) {
        set_errno(ENOMEM);
        return -1;
    }
    // After ipc::call, req contains the reply. Some IPC paths use req-as-reply,
    // others use a separate buffer — match the local convention. Suppose req
    // is mutated in place:
    let status = req.words[0];
    if status != 0 {
        set_errno(ENOMEM);
        return -1;
    }
    let write_token = req.words[1];
    let read_token  = req.words[2];
    let pipe_id     = req.words[3];

    let mut table = crate::fd_table::FD_TABLE.lock();
    let read_fd = match table.allocate(crate::fd_table::FdEntry {
        endpoint: read_token,
        kind: crate::fd_table::FdKind::PipeRead { pipe_id },
    }) {
        Some(fd) => fd,
        None => {
            // Cleanup: ask procmgr to close the pipe.
            let _ = close_pipe(procmgr_ep, pipe_id);
            set_errno(ENOMEM);
            return -1;
        }
    };
    let write_fd = match table.allocate(crate::fd_table::FdEntry {
        endpoint: write_token,
        kind: crate::fd_table::FdKind::PipeWrite { pipe_id },
    }) {
        Some(fd) => fd,
        None => {
            table.close(read_fd);
            let _ = close_pipe(procmgr_ep, pipe_id);
            set_errno(ENOMEM);
            return -1;
        }
    };
    drop(table);

    unsafe {
        ptr::write(fds.offset(0), read_fd as c_int);
        ptr::write(fds.offset(1), write_fd as c_int);
    }
    0
}

pub(crate) fn close_pipe(procmgr_ep: usize, pipe_id: usize) -> Result<(), Error> {
    let mut req = Message::new(PROCMGR_PIPE_CLOSE_LABEL, [pipe_id, 0, 0, 0, 0, 0], 1);
    crate::ipc::call(procmgr_ep, &mut req, crate::IpcFlags::empty())
        .map(|_| ())
}
```

```rust
fn read_pipe(endpoint: usize, buffer: &mut [u8]) -> ssize_t {
    // Recv a TTY_WRITE_LABEL-shaped message (writer used send_with_payload
    // with that label; payload bytes are the data).
    let mut reply_buf = [0u8; 512];
    match crate::syscall::ipc_recv(endpoint, &mut reply_buf, crate::IpcFlags::empty()) {
        Ok(bytes) => {
            if bytes <= core::mem::size_of::<Message>() {
                return 0;  // EOF marker / empty
            }
            let data_len = bytes - core::mem::size_of::<Message>();
            let to_copy = data_len.min(buffer.len());
            buffer[..to_copy].copy_from_slice(
                &reply_buf[core::mem::size_of::<Message>()..][..to_copy],
            );
            to_copy as ssize_t
        }
        Err(crate::Error::TokenInvalid) | Err(crate::Error::Closed) => 0,  // EOF
        Err(e) => crate::errno::return_error(e),
    }
}
```

```rust
    // argv[0] is "/bin/cat" or "cat"; operands start at index 1.
    let operands: Vec<_> = args.into_iter().skip(1).collect();

    let Ok(vfs_endpoint) = registry::subscribe_output("vfs", "main") else {

        return cat_stdin();
    }

    let mut exit_code = 0;
    for path in operands {
        let resolved = libcluu::posix::resolve_path(&path);
        if let Err(_) = cat_file(&vfs, &resolved) {
            exit_code = 1;
        }
    }
    exit_code

fn cat_file(vfs: &VfsClient, path: &str) -> Result<(), ()> {
    let file = vfs.open(path).map_err(|_| ())?;
    let total = file.size;
    let mut offset = 0usize;
    let mut buf = [0u8; CHUNK];

    while offset < total {
        let want = (total - offset).min(CHUNK);
        let n = match vfs.read(file, offset, &mut buf[..want]) {
            Ok(n) => n,
            Err(_) => {
                let _ = vfs.close(file);
                return Err(());
            }
        };

            break;
        }
        // Write to fd 1 (stdout).
        let written = unsafe {
            libcluu::posix::file::write(1, buf.as_ptr() as *const _, n)
        };
        if written < 0 {
            let _ = vfs.close(file);
            return Err(());
        }
        offset += n;
    }
    let _ = vfs.close(file);
    Ok(())
}
```

```rust
    let mut show_line_no = false;
    let mut case_insensitive = false;
    let mut invert = false;

    while let Some(arg) = iter.next() {
        match arg.as_str() {
            "-n" => show_line_no = true,
            "-i" => case_insensitive = true,
            "-v" => invert = true,

                return 2;
            }
            _ => {
                pattern = Some(arg);
                break;
            }
        }
    }
    let Some(pattern) = pattern else {
        let _ = libcluu::debug_print("grep: usage: grep [-n] [-i] [-v] PATTERN [FILE]");
        return 2;
    };
    let needle = if case_insensitive { pattern.to_lowercase() } else { pattern };

    let file_path = iter.next();

    let mut buf: Vec<u8> = Vec::new();

        if let Err(_) = read_whole_file_into(&path, &mut buf) {
            return 2;

        // Stdin: read until EOF.
        let mut chunk = [0u8; 4096];

            let n = unsafe {
                libcluu::posix::file::read(0, chunk.as_mut_ptr() as *mut _, chunk.len())
            };
            if n <= 0 {
                break;
            }
            buf.extend_from_slice(&chunk[..n as usize]);
        }

    let text = match core::str::from_utf8(&buf) {
        Ok(s) => s,
        Err(_) => {
            return 2;  // invalid UTF-8
        }
    };

    let mut any_match = false;
    for (lineno, line) in text.lines().enumerate() {
        let hay = if case_insensitive {
            alloc::borrow::Cow::Owned(line.to_lowercase())
        } else {
            alloc::borrow::Cow::Borrowed(line)
        };
        let matched = hay.contains(needle.as_str());
        let keep = matched ^ invert;
        if keep {
            any_match = true;
            let line_out = if show_line_no {
                alloc::format!("{}:{}\n", lineno + 1, line)
            } else {
                alloc::format!("{}\n", line)
            };
            let _ = unsafe {
                libcluu::posix::file::write(
                    1,
                    line_out.as_ptr() as *const _,
                    line_out.len(),
                )
            };
        }
    }

    if any_match { 0 } else { 1 }
}

        vfs_endpoint,
        libcluu::registry::control_endpoint(),

    dst.reserve(file.size);
    let mut offset = 0;
    let mut chunk = [0u8; 4096];
    while offset < file.size {
        let want = (file.size - offset).min(chunk.len());
        let n = vfs.read(file, offset, &mut chunk[..want]).map_err(|_| ())?;
        if n == 0 { break; }
        dst.extend_from_slice(&chunk[..n]);
        offset += n;
    }
    let _ = vfs.close(file);
    Ok(())
}
```

```rust
fn run_multi(
    stdout: usize,
    context: &mut CommandContext,
    pipeline: &Pipeline,
) -> Result<i32> {
    let n = pipeline.commands.len();
    debug_assert!(n >= 2);

    // 1) Allocate N-1 pipes via PROCMGR_PIPE_CREATE.
    let mut pipes: Vec<PipeHandles> = Vec::with_capacity(n - 1);
    for _ in 0..(n - 1) {
        let p = match procmgr_pipe_create(context) {
            Ok(p) => p,
            Err(e) => {
                drop_remaining_pipes(&mut pipes, context);
                return Err(e);
            }
        };
        pipes.push(p);
    }

    // 2) Determine each command's stdin/stdout endpoints.
    let stdin0 = libcluu::boot::stdin_token();
    let stdout_last = stdout;
    let mut child_pids: Vec<usize> = Vec::with_capacity(n);
    let mut last_status: i32 = 0;

    for (i, cmd) in pipeline.commands.iter().enumerate() {
        let in_ep  = if i == 0 { stdin0 } else { pipes[i-1].read_token };
        let out_ep = if i == n - 1 { stdout_last } else { pipes[i].write_token };

        let pid = spawn_command(cmd, in_ep, out_ep, context)?;
        child_pids.push(pid);
    }

    // 3) Drop shell's local copies of each pipe's tokens — children own their
    //    handles via the spawn protocol's stdin/stdout slots; the shell must
    //    not keep tokens alive or EOF won't propagate.
    for p in &pipes {
        let _ = libcluu::syscall::token_revoke(p.write_token);
        let _ = libcluu::syscall::token_revoke(p.read_token);
    }

    // 4) Wait for all children. $? = last command's exit status.
    for (i, pid) in child_pids.iter().enumerate() {
        let status = wait_for_pid(*pid, context)?;
        if i == n - 1 {
            last_status = status;
        }
    }

    // 5) Close pipes in procmgr.
    for p in pipes {
        let _ = procmgr_pipe_close(context, p.pipe_id);
    }

    Ok(last_status)
}

struct PipeHandles {
    write_token: usize,
    read_token: usize,
    pipe_id: usize,
}

fn procmgr_pipe_create(context: &mut CommandContext) -> Result<PipeHandles> {
    let ep = context.procmgr_spawn_endpoint()?;  // existing helper that returns
                                                   // procmgr's main endpoint
    let mut req = Message::new(PROCMGR_PIPE_CREATE_LABEL, [0; 6], 0);
    libcluu::ipc::call(ep, &mut req, IpcFlags::empty())?;
    let status = req.words[0];
    if status != 0 {
        return Err(libcluu::Error::ResourceLimit);
    }
    Ok(PipeHandles {
        write_token: req.words[1],
        read_token:  req.words[2],
        pipe_id:     req.words[3],
    })
}

fn procmgr_pipe_close(context: &mut CommandContext, pipe_id: usize) -> Result<()> {
    let ep = context.procmgr_spawn_endpoint()?;
    let mut req = Message::new(PROCMGR_PIPE_CLOSE_LABEL, [pipe_id, 0, 0, 0, 0, 0], 1);
    libcluu::ipc::call(ep, &mut req, IpcFlags::empty())?;
    Ok(())
}

fn drop_remaining_pipes(pipes: &mut Vec<PipeHandles>, context: &mut CommandContext) {
    for p in pipes.drain(..) {
        let _ = procmgr_pipe_close(context, p.pipe_id);
    }
}
```

- `spawn_command`: render the `Command`'s words to argv strings; resolve to `/bin/X` if not a builtin; use the existing `container_run` helper but pass `in_ep` / `out_ep` through the spawn protocol (extends or replaces the existing `stdin`/`stdout` defaults).

## Acceptance criteria (mirror of spec §12)

The work is "done" when all of the following are true:

1. `cat /etc/motd | grep CLUU | head -3` typed at the interactive shell prints the expected three lines.
2. `yesprobe | head -3` terminates promptly (no infinite spin) — SIGPIPE confirmed.
3. `cmd 2>&1 | grep err` correctly funnels stderr through the pipe.
4. `cmd 2> /tmp/err` writes stderr to a VFS file.
5. `false | true; echo $?` prints `0`. `true | false; echo $?` prints `1`.
6. The full harness matrix is green (including all new `l2_pipe_*` and `l2_redir_*` cases). No SLO regression beyond 5%.
7. `CatBuiltin`, `LsBuiltin`, `PsBuiltin`, `TouchBuiltin` are deleted from `commands.rs`. `/bin/cat`, `/bin/ls`, `/bin/ps`, `/bin/touch`, `/bin/grep`, `/bin/head`, `/bin/wc` exist as real binaries.

## Out of scope (per spec §13)

- SharedRing-backed pipes (deferred — same `pipe(2)` API, different impl).
- `set -o pipefail`.
- Named FIFOs (`mkfifo`).
- Privileged binary migration (`su`, `sudo`, `container`, `poweroff`, `reboot`).
- Test scaffolding namespace cleanup.
- Process substitution `<(cmd)`, here-documents, here-strings, `&>`, fd numbers other than 0/1/2.
- Non-blocking pipe fds.
